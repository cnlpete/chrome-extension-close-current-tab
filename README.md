# Close Current Tab

A small Chrome/Chromium extension that adds a toolbar button to close the
current tab.

## Install

1. Open `chrome://extensions` (or `chromium://extensions`).
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this extension's folder.
4. Pin **Close Current Tab** from the Extensions menu.

Click the extension’s X button to close the active tab.

## Limitations

Browser extensions cannot add buttons directly to the browser’s tab strip or
detect whether native vertical tabs are enabled. The button appears in the
extensions toolbar, and its position is controlled by the browser and user.
